# 目录密匣 (DirLocker)

轻量级跨平台目录密码保护工具，支持 **Windows 10 / 11 (x64)** 与 **银河麒麟 V10 SP1（Ubuntu 20.04 x64）**。  
采用**零文件内容改动**机制，保护目录隐私与防止误删，绝不加密、改写或破坏目录内原始文件。

- **当前版本**：`v2.1.1`
- **开发人员**：`yinchaow & Gemini`
- **开源仓库**：<https://github.com/yinchaow/dirlocker>
- **开源协议**：[MIT License](LICENSE)

## 核心特性

- **双重密码体系**：支持统一主密码与单目录独立密码，随时自由切换、修改；设置或改密时附带防遗忘风险确认提示，密码框支持一键显示/隐藏。
- **快捷验证解锁**：
  - **Windows 端**：锁定目录同盘安全移动至受 ACL 保护的隐藏系统保护区，原位置生成统一蓝白锁徽章入口（`.dlock` 隐藏扩展名、无快捷方式角标），双击直接弹出解锁弹窗。
  - **银河麒麟端**：由系统守护服务 `dirlockerd`（`root` 权限）安全转入受保护 Vault（`0700` + 不可变标记 `chattr +i`），原位置生成受保护蓝锁入口，并集成 Peony 文件管理器右键菜单。
- **批量拖拽加锁**：支持将单个或多个真实目录直接拖入主界面批量锁定（自动拦截非目录文件、系统根目录与嵌套路径）。
- **一键全锁与自动回锁**：
  - 全局快捷键 `Ctrl + Alt + L` 及系统托盘一键全锁；
  - 闲置超时自动回锁（默认 5 分钟，可调 `0~1440` 分钟）；
  - 系统锁屏 / 休眠前自动回锁；退出程序前自动检测未锁目录并提示锁定。
- **数据安全与应急恢复**：查看程序内置「应急恢复说明」前需验证主密码；仓库内另提供 [使用与应急恢复说明](docs/RECOVERY.md)。

## 下载与安装

### Windows 10 / 11 (x64)
运行安装程序 `DirLocker_Setup_v2.1.1.exe` 按向导安装（默认安装至 `C:\Program Files\DirLocker`，支持右键菜单、开机托盘自启与系统标准卸载）。

### 银河麒麟 V10 SP1 / Ubuntu 20.04 (x64)
```bash
sudo dpkg -i dirlocker_2.1.1_amd64.deb
# 若提示缺少依赖，执行：
sudo apt-get install -f
```
或解压离线安装包后执行 `sudo ./install.sh`。

## 从源码编译

在安装了 Docker 的 Linux 环境中执行（自动构建 `ubuntu:20.04` 交叉编译环境，包含 glibc 2.31 与 MinGW-w64）：

```bash
./scripts/build_all.sh
```

编译产物位于 `dist/kylin-ubuntu20.04/` 与 `dist/windows/`。
