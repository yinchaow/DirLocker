# 目录密匣 (DirLocker)

轻量级跨平台目录密码保护工具，支持 **Windows 10 / 11 (x64)** 与 **银河麒麟 V10 SP1（Ubuntu 20.04 x64）**。  
采用**零文件内容改动**机制，保护目录隐私与防止误删，绝不加密、改写或破坏目录内原始文件。

- **当前版本**：`v2.2.1`
- **开发人员**：`yinchaow & Gemini`
- **开源仓库**：<https://github.com/yinchaow/DirLocker>
- **开源协议**：[MIT License](LICENSE)

## 核心特性

- **双重密码与防爆破冷却**：支持统一主密码与单目录独立密码，随时自由切换、修改；连续输错密码达 5 次触发递增退避冷却（30s / 60s / 300s），严格仅限时长等待、绝不删除用户数据。
- **主界面可选验证锁**：可在「安全设置」中开启“打开主窗口需验证主密码”（最小化或关闭至托盘后自动重锁）；开启后日常双击 `.dlock` / `.desktop` 解锁目录仍直接弹窗，不阻断快捷流程。
- **严格防占用保护**：锁定前主动检测内部文件句柄、终端工作目录及打开中的资源管理器窗口（记事本等读完即关闭句柄的程序不影响锁定）；若被第三方程序占用则跳过锁定并点名占用进程提示（Windows 端默认阻止；可选在设置中开启原位 ACL 降级锁定，同时附带伴随 `.dlock` 解锁入口、闲置后后台自动升级入库及托盘高亮提示）。
- **快捷验证解锁**：
  - **Windows 端**：锁定目录同盘安全移动至受 ACL 保护的隐藏系统保护区，原位置生成统一蓝白锁徽章入口（`.dlock` 隐藏扩展名、无快捷方式角标），双击直接弹出解锁弹窗；原位降级模式另附伴随 `.dlock` 解锁入口。
  - **银河麒麟端**：由系统守护服务 `dirlockerd`（`root` 权限）安全转入受保护 Vault（`0700` + 不可变标记 `chattr +i`），原位置生成受保护蓝锁入口，并集成 Peony 文件管理器右键菜单。
- **批量拖拽与自定义全锁热键**：支持批量拖拽目录锁定；支持自定义全局一键全锁快捷键（默认 `Ctrl + Alt + K`，避开麒麟系统默认锁屏热键冲突，含实时按键录入与冲突探测）、托盘一键全锁、闲置自动回锁（`0~1440` 分钟）以及退出前未锁目录提醒。
- **保护区体检与安全恢复**：内置主密码鉴权的「保护区体检与一键修复」工具与「应急恢复说明」；所有修复绝不静默删除任何目录内容。仓库内另提供 [使用与应急恢复说明](docs/RECOVERY.md)。

## 下载与安装

### Windows 10 / 11 (x64)
运行安装程序 `DirLocker_Setup_v2.2.1.exe` 按向导安装（默认安装至 `C:\Program Files\DirLocker`，支持右键菜单、开机托盘自启与系统标准卸载）。

> [!IMPORTANT]
> **关于 Windows 11 “智能应用控制 (Smart App Control / SAC)” 与第三方杀软的说明**：
> - 微软官方的 **Smart App Control (SAC)** 是 Win11 系统底层基于代码完整性的零信任安全防护，**不支持针对单文件、目录或进程添加白名单/排除项**（任何工具与安装程序均无法通过命令或注册表为其添加豁免）。
> - 若电脑安装了 **360、火绒等第三方安全软件**，Windows Defender 防病毒会被系统自动关闭，导致防病毒选项中的“排除项”变为不可用；但 **SAC 独立于杀毒软件仍会在系统底层强制拦截未签名或新版本二进制文件**。
> - 本工具为纯本地开源项目，未购买昂贵的商业代码签名证书。若在开启了 SAC 的 Win11 上运行时被提示阻止，需手动关闭 SAC：打开 **Windows 安全中心 $\rightarrow$ 应用和浏览器控制 $\rightarrow$ 智能应用控制设置 $\rightarrow$ 选择“关闭 (Off)”** 即可。

### 银河麒麟 V10 SP1 / Ubuntu 20.04 (x64)
```bash
sudo dpkg -i dirlocker_2.2.1_amd64.deb
# 若提示缺少依赖，执行：
sudo apt-get install -f
```
或解压离线安装包后执行 `sudo ./install.sh`（安装/升级过程会自动退出正在运行的旧版桌面程序并更新守护服务）。

## 从源码编译

在安装了 Docker 的 Linux 环境中执行（自动构建 `ubuntu:20.04` 交叉编译环境，包含 glibc 2.31 与 MinGW-w64）：

```bash
./scripts/build_all.sh
```

编译产物位于 `dist/kylin-ubuntu20.04/` 与 `dist/windows/`。
