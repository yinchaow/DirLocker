# 目录密匣 (DirLocker) — 使用与应急恢复说明

## 核心安全原则（为何不会丢失数据）

目录密匣采用**零文件内容改动机制**：
- **不加密或改写任何文件内容**，不压缩、不打包；
- Windows 端通过同盘原子移动至受 ACL 保护的隐藏系统目录（`%LOCALAPPDATA%\DirLocker\Vault` 或各盘根目录下的 `$目录密匣_重要数据保护区_切勿删除`）并在原处生成防误删的 `.dlock`（隐藏扩展名）加密入口；银河麒麟端修改目录属主与不可变标记；
- 即使入口文件被强删、软件被卸载或状态文件受损（内置 `.bak` 自动恢复），目录内的全部原始文件都完整无损。

## 常规使用方式

### Windows 10 / 11
1. 运行安装程序 `DirLocker_Setup_v2.2.0.exe` 按图形化向导完成安装，自动注册：
   - 文件夹右键菜单「使用 目录密匣 锁定/解锁」（Windows 11 请在右键后点击“显示更多选项”或按 `Shift + 右键`）
   - 无角标蓝白锁标加密目录图标（`.dlock`）与开机后台托盘自启
2. 首次运行请设置**主密码**。
3. 锁定新目录时可选择：
   - **使用主密码（默认）**
   - **设置独立密码**
4. **一键全锁**：按全局快捷键（默认 `Ctrl + Alt + L`，可在设置中自定义），或点击托盘右键「一键全部锁定」。
5. **安全策略与体检**：在「安全设置」中可配置“无操作 N 分钟自动回锁”、打开主窗口验证主密码、严格防占用策略及自定义快捷键；可通过设置菜单或托盘执行「保护区体检与一键修复」。

### 银河麒麟 V10 SP1（Ubuntu 20.04 x64）
1. 安装 `.deb` 安装包：
   ```bash
   sudo dpkg -i dirlocker_2.2.0_amd64.deb
   # 若提示缺少依赖，执行：
   sudo apt-get install -f
   ```
   安装完成后如需立即在 Peony 文件管理器中显示右键菜单，可注销重新登录或执行 `peony -q` 重启文管进程。
2. 也可使用离线安装包中的 `sudo ./install.sh` 进行安装。
3. 锁定目录时由后台服务 `dirlockerd`（`root` 权限）将目录移入受保护的 Vault 目录（`root:root` `0700`）并开启不可变标记（`chattr +i`），原位置生成防误删加密入口（`.desktop`）；普通用户在终端里无法直接绕过。

## 应急数据恢复（忘记密码 / 状态文件丢失 / 卸载后手动解锁）

如果忘记密码、误删状态文件或需要在卸载后手动恢复目录，请按对应系统执行以下无损还原步骤：

### Windows 10 / 11

> **重要提示**：请使用 **命令提示符（CMD）**，不要用 PowerShell（PowerShell 双引号中的 `$目录密匣_...` 会被当作变量解析）。普通 CMD 即可；若个别目录提示无权操作，请改用**管理员身份**运行 CMD。

#### 1. 情形一：原目录不见了、原地只剩 `.dlock` 锁标入口（最常见，包括忘记密码 / 误删状态文件 / 卸载后）
真实目录完好存放在以下隐藏系统保护区之一：
- **系统盘（与 `%LOCALAPPDATA%` 同盘）**：`%LOCALAPPDATA%\DirLocker\Vault`
- **其他磁盘（以 `D:` 为例，其他盘替换盘符）**：`D:\$目录密匣_重要数据保护区_切勿删除`

按顺序执行：
1. **查看 `.dlock` 中记录的 `<id>` 与原路径**：  
   由于 `.dlock` 按标准 JSON 使用 UTF-8 编码存储，中文 Windows CMD 默认处于 GBK (`936`) 代码页，直接 `type` 会出现中文乱码。先执行 `chcp 65001` 切换为 UTF-8（或直接运行 `notepad "你的原目录路径.dlock"`）即可正常查看：
   ```cmd
   chcp 65001
   type "C:\原父目录\目录名.dlock"
   ```
2. **解除保护区访问限制并列出其中的 `<id>` 子目录**：
   ```cmd
   :: 若原目录在系统盘（如 C 盘）：
   icacls "%LOCALAPPDATA%\DirLocker\Vault" /remove:d *S-1-1-0
   dir /a "%LOCALAPPDATA%\DirLocker\Vault"

   :: 若原目录在其他盘（如 D 盘）：
   icacls "D:\$目录密匣_重要数据保护区_切勿删除" /remove:d *S-1-1-0
   dir /a "D:\$目录密匣_重要数据保护区_切勿删除"
   ```
3. **解除目标 `<id>` 子目录拒绝权限、去掉隐藏/系统属性，并移回原路径恢复原名**：
   ```cmd
   :: 示例（将 "保护区路径" 替换为上面对应的 Vault 或 $目录密匣_重要数据保护区_切勿删除）：
   icacls "保护区路径\<id>" /remove:d *S-1-1-0
   attrib -s -h "保护区路径\<id>"
   move "保护区路径\<id>" "原目录完整路径"
   ```
4. **删除残余 `.dlock` 入口文件**（入口文件本身带有只读属性与防删 ACL，直接 `del` 会提示拒绝访问，需先解除）：
   ```cmd
   icacls "原目录完整路径.dlock" /remove:d *S-1-1-0
   attrib -r "原目录完整路径.dlock"
   del "原目录完整路径.dlock"
   ```
5. （可选）如果确认保护区已彻底清空，可顺手移除空壳目录：
   ```cmd
   attrib -s -h "保护区路径"
   rmdir "保护区路径"
   ```

#### 2. 情形二：原文件夹仍在原地（不是单个 `.dlock` 替代文件），仅提示拒绝访问（原位 ACL 锁定 / 网络共享盘）
若同级目录下还存在伴随解锁入口 `原目录名（已锁定，点此解锁）.dlock`，先按情形一第 4 步同样的方法解除拒绝 ACL 并删除该伴随 `.dlock` 文件（可选），再在 CMD 中执行：
```cmd
icacls "D:\你的目录路径" /remove:d *S-1-1-0
```
若提示权限不足，请以管理员身份打开 CMD，先取得所有权再删除拒绝条目：
```cmd
takeown /f "D:\你的目录路径"
icacls "D:\你的目录路径" /remove:d *S-1-1-0
```
或者右键文件夹 $\rightarrow$ **属性** $\rightarrow$ **安全** $\rightarrow$ **高级**，删除其中的 `Everyone / 拒绝` 条目即可。

### 银河麒麟 V10 SP1 / Linux

#### 1. 保护区移动模式（原位置留有 `.desktop` 加密入口）
真实目录存放在以下隐藏保护区之一：
- 系统根目录保护区：`/var/lib/dirlocker/vault/<id>`
- 独立分区保护区：`所在分区根目录/.dirlocker_vault_do_not_delete/<id>`

```bash
# (0) 查看入口记录的 ID（也可直接 sudo ls -la 查看保护区目录）
cat "/原/目录/路径.desktop"

# (1) 解除不可变标记并移回原路径
sudo chattr -i "保护区路径/<id>" 2>/dev/null || true
sudo mv "保护区路径/<id>" "/原/目录/路径"

# (2) 恢复属主与正常访问权限
sudo chown "$(id -u):$(id -g)" "/原/目录/路径"
sudo chmod 755 "/原/目录/路径"

# (3) 删除残余加密入口文件（.desktop 或 .dlock）
sudo chattr -i -a "/原/目录/路径.desktop" "/原/目录/路径.dlock" 2>/dev/null || true
sudo rm -f "/原/目录/路径.desktop" "/原/目录/路径.dlock"
```

#### 2. 原位权限锁定模式（旧版兼容）
```bash
sudo chattr -i "/你的/目录/路径" 2>/dev/null || true
sudo chown "$(id -u):$(id -g)" "/你的/目录/路径"
sudo chmod 755 "/你的/目录/路径"
```
执行后即可立即无损恢复正常访问。
